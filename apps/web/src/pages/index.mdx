# ENS Resolver Record Verification

ENS resolver records return values selected by a resolver. They do not by
themselves establish that current ENS authority signed the value or that an
external target published matching evidence.

This protocol evaluates one target resolver record against:

1. a compact verification descriptor stored in ENS;
2. a common claim bound to the exact live resolver value;
3. a signature from current ENS authority;
4. method-specific target evidence;
5. expiry, freshness, and revocation rules.

A successful evaluation returns `verified` with relationship `authorization`,
`control`, or `attestation`. Any required check that does not pass returns
`none`.

## Example

```text
text("url") = "https://example.com/profile"
text("verification[text][url]") = "ensrv1 a=1 m=https-origin.v1"
```

The verifier derives target `https://example.com`, loads the proof from the
method-defined well-known path, compares the claim with the live URL bytes,
validates current ENS authority, and checks current origin publication.

The result does not establish that the website is safe, official, legally
owned, or non-malicious.
