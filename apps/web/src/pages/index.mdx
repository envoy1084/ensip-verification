# Record Verification

An ENS name can store records such as a website URL, an address, an email
address, or an agent endpoint.

```text
alice.eth
└─ text("url") = "https://example.com"
```

The resolver tells a client what value is set. It does not tell the client
whether the website or account also recognizes that record.

Record Verification adds a second text record that tells clients how to
check the value.

```text
text("verification[text][url]") = "ensrv1 a=1 m=https-origin.v1"
```

For this example, a verifier checks:

1. the current `url` record on `alice.eth`;
2. the verification text record on the same name;
3. a signature from the current authority for `alice.eth`;
4. a proof published by `https://example.com`;
5. the proof's expiry.

If every check passes, the client returns `verified/control`. Otherwise it
returns `none`. The original `url` record still resolves in either case.

Verification describes what was checked. It does not mean the website is safe,
official, or endorsed by ENS.
