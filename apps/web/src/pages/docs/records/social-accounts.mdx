# Social and Service Accounts

Examples:

```text
text("com.github") = "alice"
text("com.twitter") = "alice"
text("org.telegram") = "alice"
```

The initial normative option is:

```text
authority-signature.v1
```

This proves current exact-name authority authorized the text value. It does not
prove provider account control.

Provider control requires a concrete immutable profile such as a future
`service-account.github.v1`. That profile must define stable account ID,
handle-to-ID mapping, username reuse, user versus organization behavior, exact
proof surface, collaborator risk, API version, revocation, cache limits, and UI
meaning.

Generic `service-account` and wildcard `service-account.<provider>` are abstract
families and invalid descriptor values.
