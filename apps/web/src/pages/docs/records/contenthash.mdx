# Contenthash Records

Contenthash does not expose one universal external controller. The initial
protocol therefore uses authorization, not control:

```text
text("verification[contenthash]") =
  "ensrv1 a=1 m=authority-signature.v1 u=https://proofs.example/content/1 h=0x..."
```

The claim uses:

```text
recordType = contenthash
recordKey = ""
target = ""
valueHash = keccak256(raw contenthash resolver bytes)
```

A positive result means current exact-name authority explicitly authorized the
live contenthash bytes. This is useful when a resolver writer is delegated.

It does not prove content authorship, publisher identity, safety, availability,
legality, or control of a mutable gateway. Future publisher or content-system
profiles may add separate control evidence.
