# Email Records

Example target:

```text
text("email") = "alice@example.com"
```

Initial options:

| Method                    | Relationship    | Meaning                                                       |
| ------------------------- | --------------- | ------------------------------------------------------------- |
| `authority-signature.v1`  | `authorization` | Current ENS authority signed exact email text.                |
| `dns-txt.email-domain.v1` | `control`       | DNSSEC-authenticated `example.com` zone published proof hash. |

DNS domain control does not prove access to `alice@example.com`. The email
profile accepts a simple mailbox form only: non-empty local part, final `@`, and
valid IDNA domain; display names and comments are unsupported.

Mailbox control requires a future concrete issuer or provider profile with
private challenge, exact credential format, revocation, and client trust policy.
The abstract `issuer-attestation` family is not a valid descriptor method.
