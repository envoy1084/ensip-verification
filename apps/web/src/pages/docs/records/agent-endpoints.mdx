# Agent Endpoint Records

ENSIP-26 endpoint keys can contain brackets:

```text
text("agent-endpoint[mcp]") = "https://agent.example.com/mcp"
text("verification[text][agent-endpoint[mcp]]") =
  "ensrv1 a=1 m=https-origin.v1"
```

Verification key construction is exact concatenation. The final key contains
two closing brackets because one belongs to the target key.

Supported methods:

| Method                      | Relationship                                             |
| --------------------------- | -------------------------------------------------------- |
| `authority-signature.v1`    | Current authority authorized exact endpoint text.        |
| `https-origin.v1`           | Endpoint HTTPS origin published a matching proof.        |
| `dns-txt.https-endpoint.v1` | DNSSEC-authenticated endpoint host published proof hash. |

The raw value hash binds the complete endpoint, including path. HTTPS control is
origin-level and does not prove protocol conformance, agent safety, capability,
authorization to act, or correct endpoint behavior.
