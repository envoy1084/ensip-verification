# Verifying Agent Endpoint Records

## Overview

ENSIP-26 defines `agent-endpoint[<protocol>]` text records. Version 1 can verify
authority authorization, HTTPS-origin publication, or DNSSEC publication for an
HTTPS endpoint.

## When To Use This Method

Use `https-origin.v1` when the endpoint origin can host a well-known proof. Use
`dns-txt.https-endpoint.v1` when the endpoint domain can publish DNSSEC evidence.
Use `authority-signature.v1` when target-side evidence is not required.

## Records To Set

```text
text("agent-endpoint[mcp]") = "https://agent.example.com/mcp"
text("verification[text][agent-endpoint[mcp]]") = "ensrv1 a=1 m=https-origin.v1"
```

The outer verification key is exact concatenation. Do not parse the inner
brackets.

## Proof To Publish

For `https-origin.v1`, publish the common envelope at:

```text
https://agent.example.com/.well-known/ens-record-verification/<proof-key-hex>
```

The claim target is `https://agent.example.com`.

## Verification Flow

1. Resolve the exact endpoint string and descriptor.
2. Hash the exact endpoint string.
3. Derive the HTTPS origin.
4. Fetch the proof from the deterministic well-known path.
5. Validate the common claim and current ENS authority signature.
6. Apply lifecycle and live publication freshness.
7. Return `verified/control`.

## Failure Cases

| Condition                       | Result                   |
| ------------------------------- | ------------------------ |
| Endpoint absent                 | `none/record_missing`    |
| Endpoint is not supported HTTPS | `none/target_mismatch`   |
| Proof unavailable               | `none/proof_unavailable` |
| Endpoint value changed          | `none/value_mismatch`    |

## Example

`agent-endpoint[mcp]` and `agent-endpoint[web]` are separate target resolver
records. Each uses a separate verification key, claim, and proof key even when
both resolve to the same origin.

## Security Notes

Endpoint verification does not validate the agent protocol, server code,
authorization policy, response content, or operational safety.
