# URL Records

Target and descriptor:

```text
text("url") = "https://example.com/profile"
text("verification[text][url]") = "ensrv1 a=1 m=https-origin.v1"
```

Supported relationships:

| Method                   | Relationship    | Evidence                                            |
| ------------------------ | --------------- | --------------------------------------------------- |
| `authority-signature.v1` | `authorization` | Current ENS authority signed exact URL bytes.       |
| `https-origin.v1`        | `control`       | HTTPS origin publishes deterministic proof.         |
| `dns-txt.url.v1`         | `control`       | DNSSEC-authenticated URL host publishes proof hash. |

`valueHash` always covers the complete exact URL string. HTTPS target excludes
path, query, and fragment; changing any of them still changes `valueHash` and
invalidates the old proof.

Use HTTPS origin when the web server can publish a well-known resource. Use DNS
when the zone is DNSSEC-signed and DNS publication is operationally preferable.

A control result proves current origin or DNS-zone participation. It does not
prove the URL path is controlled independently, the website is safe, or the
domain is official.
