# Address Records

Example:

```text
addr(60) = 0x1234567890abcdef1234567890abcdef12345678
text("verification[addr][60]") =
  "ensrv1 a=1 m=account-signature.eip155.v1 u=https://proofs.example/p/1"
```

Supported methods:

| Method                        | Relationship    | Evidence                                                                 |
| ----------------------------- | --------------- | ------------------------------------------------------------------------ |
| `authority-signature.v1`      | `authorization` | Current ENS authority signed exact native address bytes.                 |
| `account-signature.eip155.v1` | `control`       | Target EVM account signed a target-chain proof binding the common claim. |

Supported EVM mappings:

```text
coinType 60 -> eip155:1
coinType 0x80000000 | chainId -> eip155:<chainId>
```

The default EVM coin type `0x80000000`, ambiguous legacy EVM SLIP-44 types, and
non-EVM accounts require separate future profiles.

The result proves account signing control under the profile. It does not prove
safe recipient, identity, solvency, custody, or absence of malicious activity.
