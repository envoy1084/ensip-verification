# Error Reference

Use the first applicable observable error. Implementations may reorder internal
work to enforce privacy and network safety.

| Order | Error                         | Retryable             | Meaning                                                     |
| ----: | ----------------------------- | --------------------- | ----------------------------------------------------------- |
|     1 | `invalid_request`             | No                    | Invalid name or selector.                                   |
|     2 | `unsupported_record`          | Capability change     | Record profile unsupported.                                 |
|     3 | `resolution_unavailable`      | Yes                   | ENS/RPC/CCIP resolution unavailable.                        |
|     4 | `record_missing`              | Yes                   | Live target empty or absent.                                |
|     5 | `not_configured`              | Yes                   | Descriptor empty or absent.                                 |
|     6 | `invalid_descriptor`          | No                    | Descriptor malformed or contains unknown/duplicate fields.  |
|     7 | `unsupported_version`         | Capability change     | Descriptor or authority version unsupported.                |
|     8 | `unsupported_method`          | Capability change     | Concrete method unsupported.                                |
|     9 | `privacy_blocked`             | Policy change         | Required retrieval forbidden.                               |
|    10 | `proof_unavailable`           | Yes                   | Proof retrieval failed.                                     |
|    11 | `proof_integrity_mismatch`    | No                    | Pinned body hash differs.                                   |
|    12 | `proof_invalid`               | No                    | Envelope or method object invalid.                          |
|    13 | `claim_mismatch`              | No                    | Name, node, selector, authority version, or method differs. |
|    14 | `value_mismatch`              | No                    | Live raw value hash differs.                                |
|    15 | `target_mismatch`             | No                    | Canonical target differs.                                   |
|    16 | `not_yet_valid`               | Time                  | `issuedAt` exceeds allowed skew.                            |
|    17 | `expired`                     | Proof change          | Applicable validity bound reached.                          |
|    18 | `unsupported_authority`       | ENS/capability change | Exact authority cannot be authenticated.                    |
|    19 | `authority_signature_invalid` | No                    | Current exact authority rejected signature.                 |
|    20 | `target_proof_invalid`        | No                    | Method target evidence failed.                              |
|    21 | `insecure_dns`                | DNS configuration     | DNSSEC requirement not met.                                 |
|    22 | `revocation_unavailable`      | Yes                   | Required revocation status unavailable.                     |
|    23 | `revoked`                     | No                    | Required status reports revocation.                         |
|    24 | `untrusted_issuer`            | Policy change         | Issuer rejected by client policy.                           |

Public status remains `none` for every row. Retryability and debug cause let
applications distinguish checked-invalid from unavailable or not checked.
