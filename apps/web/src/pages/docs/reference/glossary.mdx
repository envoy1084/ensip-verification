# Glossary

| Term                    | Definition                                                                               |
| ----------------------- | ---------------------------------------------------------------------------------------- |
| Target resolver record  | Existing ENS resolver record being evaluated.                                            |
| Record selector         | Resolver function and its exact key or numeric parameter.                                |
| Verification record     | ENSIP-5 text record containing a verification descriptor.                                |
| Verification descriptor | Compact value selecting authority version, method, and proof resource.                   |
| Common claim            | Closed EIP-712 claim shared by all methods.                                              |
| Current ENS authority   | Exact-name account selected by the descriptor's authority algorithm.                     |
| Authority version       | Numeric identifier for a current-ENS-authority algorithm.                                |
| Method profile          | Algorithm defining target derivation and method evidence.                                |
| Target                  | Method-canonical value bound by the common claim.                                        |
| Proof resource          | External bytes containing the common proof envelope.                                     |
| Proof key               | Deterministic publication-slot identifier for a selector and method.                     |
| Live evaluation         | Evaluation against current resolver, authority, method, and lifecycle state.             |
| Evaluation block        | Block reference used for ENS and authority reads in one evaluation.                      |
| `valueHash`             | Keccak-256 of exact live resolver return bytes.                                          |
| `effectiveValidUntil`   | Earliest applicable semantic expiry.                                                     |
| `cacheUntil`            | Latest time a completed evaluation may be reused.                                        |
| Control                 | Method evidence demonstrating control of the canonical target for the exact live record. |
| Attestation             | A client-accepted issuer's attestation to the exact record-bound claim.                  |
