# Glossary

## Target Record

Existing ENS resolver record being evaluated.

## Record Selector

Resolver profile and key or parameter, such as `text("url")`, `addr(60)`, or
`contenthash()`.

## Verification Record

ENSIP-5 text record whose key identifies a target selector and whose value is a
descriptor.

## Descriptor

Closed ASCII value such as:

```text
ensrv1 a=1 m=https-origin.v1
```

## Authority Version

Numeric exact-name authority lookup and expiry algorithm signed by the claim.

## Method

Immutable target derivation and evidence algorithm.

## Proof Key

Stable, domain-separated publication slot for one name, selector, authority
version, and method.

## Authorization

Current exact-name authority signed the exact live resolver value.

## Control

Authorization plus participation by the method-defined external target.

## Attestation

Authorization plus an issuer statement accepted by client policy.

## Evaluation Block

One block number/hash used for all ENS reads in an evaluation.

## Effective Validity

Earliest applicable claim, authority, method proof, issuer, or method expiry.

## Cache Until

Latest time a cached positive result may be reused for its permitted context.
