# References

## Normative

- [RFC 2119](https://www.rfc-editor.org/rfc/rfc2119): normative requirement terms.
- [RFC 8174](https://www.rfc-editor.org/rfc/rfc8174): uppercase requirement-term interpretation.
- [RFC 4648](https://www.rfc-editor.org/rfc/rfc4648): DNS proof-key base32 encoding.
- [EIP-712](https://eips.ethereum.org/EIPS/eip-712): typed structured-data hashing and signing.
- [EIP-1271](https://eips.ethereum.org/EIPS/eip-1271): contract signature validation.
- [EIP-3668](https://eips.ethereum.org/EIPS/eip-3668): CCIP Read.
- [ENSIP-5](https://docs.ens.domains/ensip/5/): ENS text records.
- [ENSIP-7](https://docs.ens.domains/ensip/7/): contenthash records.
- [ENSIP-9](https://docs.ens.domains/ensip/9/): multichain address records.
- [ENSIP-11](https://docs.ens.domains/ensip/11/): EVM coin-type encoding.
- [ENSIP-15](https://docs.ens.domains/ensip/15/): ENS name normalization.
- [ENSIP-23](https://docs.ens.domains/ensip/23/): Universal Resolver.
- [ENSIP-24](https://docs.ens.domains/ensip/24/): arbitrary data records.
- [CAIP-2](https://standards.chainagnostic.org/CAIPs/caip-2): blockchain identifiers.
- [CAIP-10](https://standards.chainagnostic.org/CAIPs/caip-10): account identifiers.
- [WHATWG URL](https://url.spec.whatwg.org/): HTTPS target parsing and serialization.
- [RFC 4033](https://www.rfc-editor.org/rfc/rfc4033), [RFC 4034](https://www.rfc-editor.org/rfc/rfc4034), and [RFC 4035](https://www.rfc-editor.org/rfc/rfc4035): DNSSEC validation.

## Informative

- [ENSIP-25](https://docs.ens.domains/ensip/25/): parameterized ENS verification-key precedent.
- [ENSIP-26](https://docs.ens.domains/ensip/26/): agent endpoint text records.
- [RFC 8615](https://www.rfc-editor.org/rfc/rfc8615): well-known URI convention.
