# Method Family: `service-account.<provider>`

This is an abstract method family, not a production method. The identifier
`service-account` MUST NOT appear in a descriptor.

A concrete profile such as `service-account.github` must define:

- stable provider account identifier;
- handle-to-stable-ID resolution;
- username transfer and reuse behavior;
- user versus organization semantics;
- exact proof publication surface;
- collaborator and delegated-write risk;
- target canonicalization;
- proof selection and schema;
- API version, authentication, rate limits, and outage behavior;
- maximum claim and cache lifetime;
- removal and revocation behavior;
- allowed UI meaning.

Publishing a file in a repository, gist, or organization does not automatically
prove sole control of the displayed account. The concrete profile must state
exactly which provider capability participated.

No provider profile is normative in the initial release.
