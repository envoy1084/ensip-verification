# Method Profiles

| Method                                                  | What it does                                                                  |
| ------------------------------------------------------- | ----------------------------------------------------------------------------- |
| [`https-origin.v1`](./https-origin)                     | Verifies proof publication by the HTTPS origin in a URL text record.          |
| [`dns-txt.v1`](./dns-txt)                               | Verifies DNSSEC approval by the exact hostname in a URL text record.          |
| [`account-signature.<profile>.v1`](./account-signature) | Verifies a native signature from the account stored in an ENS address record. |
