# Method Profiles

| Method                                               | What it does                                                         |
| ---------------------------------------------------- | -------------------------------------------------------------------- |
| [`https-origin.v1`](./https-origin)                  | Verifies proof publication by the HTTPS origin in a URL text record. |
| [`dns-txt.url.v1`](./dns-txt)                        | Verifies DNSSEC approval by the exact hostname in a URL text record. |
| [`account-signature.eip155.v1`](./account-signature) | Verifies an EOA or ERC-1271 signature for an EVM address record.     |
| [`account-signature.bip322.v1`](./account-signature) | Verifies a BIP-322 signature for a Bitcoin address record.           |
