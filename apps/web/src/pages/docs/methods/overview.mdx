# Method Profiles

A method defines target derivation and evidence beyond current ENS resolution.

## Initial Registry

| Method                                                | Relationship    | Status                | Records                         |
| ----------------------------------------------------- | --------------- | --------------------- | ------------------------------- |
| [`authority-signature.v1`](./authority-signature)     | `authorization` | Normative             | Any supported selector          |
| [`https-origin.v1`](./https-origin)                   | `control`       | Normative             | HTTPS URL text records          |
| [`dns-txt.*.v1`](./dns-txt)                           | `control`       | Normative with DNSSEC | Profile-specific domain records |
| [`account-signature.eip155.v1`](./account-signature)  | `control`       | Normative             | Unambiguous EVM address records |
| [`service-account.<provider>`](./service-account)     | `control`       | Abstract family       | Provider account records        |
| [`issuer-attestation.<format>`](./issuer-attestation) | `attestation`   | Abstract family       | Format-defined                  |

Abstract family names and unversioned names are invalid descriptor methods.

## Profile Requirements

Every concrete method defines:

- immutable identifier and status;
- supported record selectors;
- relationship;
- descriptor field policy;
- target derivation;
- proof location and closed schema;
- binding of every signed or attested method proof to the complete common claim
  digest;
- maximum claim lifetime;
- freshness and cache limits;
- revocation behavior;
- fetch and privacy behavior;
- error mapping;
- allowed and forbidden UI language;
- positive and negative vectors.

## Version Axes

These versions have separate meanings:

| Version                | Controls                                          |
| ---------------------- | ------------------------------------------------- |
| `ensrv1`               | Descriptor and common envelope grammar.           |
| `authorityVersion`     | Exact-name authority lookup and expiry algorithm. |
| EIP-712 domain version | Common signature protocol.                        |
| Method suffix          | Immutable target-evidence algorithm.              |

Unknown versions fail closed. A verifier never falls back to an older method or
descriptor interpretation.
