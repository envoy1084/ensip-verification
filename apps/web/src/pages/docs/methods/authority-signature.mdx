# Method: `authority-signature.v1`

## Purpose

`authority-signature.v1` checks that current ENS authority signed the exact
record value. It does not check a website, domain, account, or other external
target. A successful check returns `verified/authorization`.

## Supported Records

The method supports every target resolver record defined by the base ENSIP:
`text`, `addr`, `contenthash`, and `data`.

## Discovery Descriptor

The descriptor requires `u` and permits `h`:

```text
ensrv1 a=1 m=authority-signature.v1 u=https://proofs.example/record.json
```

Use `h` when the publisher requires byte-level integrity for a mutable URI.

## Publisher Flow

1. Resolve the live target resolver record.
2. Construct the selector and exact `valueHash`.
3. Set `target` to the empty string.
4. Construct the common claim with a lifetime no longer than 90 days.
5. Sign the claim with the current ENS authority.
6. Publish the proof envelope at descriptor `u`.
7. If used, calculate `h` from the published response body and add it to the
   descriptor.
8. Set the verification descriptor in ENS.

## Proof Location

The proof location is descriptor `u`. Version 1 permits HTTPS. Clients apply the
common retrieval policy.

## Proof Payload

```json
{
  "v": "ensrv1",
  "claim": {
    "name": "alice.eth",
    "node": "0x787192fc5378cc32aa956ddfdedbf26b24e8d78e40109add0eea2c1a012c3dec",
    "recordType": "contenthash",
    "recordKey": "",
    "valueHash": "0x<64-lowercase-hex>",
    "authorityVersion": "1",
    "method": "authority-signature.v1",
    "target": "",
    "issuedAt": "1783728000",
    "validUntil": "1786320000"
  },
  "authoritySignature": "0x<65-byte-signature>",
  "methodProof": {}
}
```

## Verifier Flow

1. Complete common name, resolution, descriptor, envelope, and claim checks.
2. Require `claim.target` to equal the empty string.
3. Resolve current ENS authority and validate `authoritySignature`.
4. Require `methodProof` to be an empty object.
5. Apply common lifecycle checks.

## Validation Rules

| Check                                            | Failure                       |
| ------------------------------------------------ | ----------------------------- |
| `u` absent or forbidden descriptor field present | `invalid_descriptor`          |
| `h` present and proof bytes do not match         | `proof_integrity_mismatch`    |
| Non-empty target                                 | `target_mismatch`             |
| Non-empty or malformed `methodProof`             | `proof_invalid`               |
| Current ENS authority signature invalid          | `authority_signature_invalid` |

## Result

Successful validation returns `verified/authorization`.

## Cache And Lifecycle

Maximum claim lifetime is 90 days. `effectiveValidUntil` includes claim and
authority expiry. Descriptor deletion, target value change, or authority change
invalidates the proof after a live evaluation.

## Security Considerations

The method contains no target-side evidence. It does not establish control of a
website, account, domain, content publisher, or service provider.

## UI Copy

Allowed:

- `Current ENS authority authorized this exact record.`

Forbidden:

- `Control of the external target was verified.`
- `Official record.`
- `Safe record.`

## Example

```text
contenthash() = <raw contenthash bytes>
text("verification[contenthash]") = "ensrv1 a=1 m=authority-signature.v1 u=https://proofs.example/alice-contenthash.json"
```

The verifier hashes the raw contenthash bytes, validates the common claim and
current ENS authority signature, and returns `verified/authorization`.
