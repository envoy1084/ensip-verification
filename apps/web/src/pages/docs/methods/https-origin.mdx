# Method: `https-origin.v1`

## Purpose

`https-origin.v1` demonstrates control of the serialized HTTPS origin derived
from an ENS text record. The origin must serve a proof bound to the exact live
record and its current ENS authority. A successful check returns
`verified/control`.

## Supported Records

The method supports text records whose exact value is an absolute HTTPS URL,
including `text("url")` and HTTPS `agent-endpoint[...]` records.

## Discovery Descriptor

The proof location is deterministic. `u` and `h` are forbidden.

```text
ensrv1 a=1 m=https-origin.v1
```

## Publisher Flow

1. Resolve the live text record.
2. Derive the serialized HTTPS origin.
3. Construct the common claim with a lifetime no longer than 30 days.
4. Sign the claim with current ENS authority.
5. Calculate `proofKey`.
6. Publish the envelope at the well-known path on the derived origin.
7. Set the verification descriptor in ENS.

## Proof Location

```text
<origin>/.well-known/ens-record-verification/<proof-key-hex>
```

`proof-key-hex` is the 32-byte proof key encoded as 64 lowercase hexadecimal
digits without `0x`.

The response uses status 200 and media type:

```text
application/ens-record-verification+json
```

## Proof Payload

The payload is the common envelope. `methodProof` is empty because live
same-origin publication is the method evidence.

```json
{
  "v": "ensrv1",
  "claim": {
    "name": "alice.eth",
    "node": "0x787192fc5378cc32aa956ddfdedbf26b24e8d78e40109add0eea2c1a012c3dec",
    "recordType": "text",
    "recordKey": "url",
    "valueHash": "0x34174bbdf078fba55709ff82e2d5929de2e915c964d18dc57907afc851781142",
    "authorityVersion": "1",
    "method": "https-origin.v1",
    "target": "https://example.com",
    "issuedAt": "1783728000",
    "validUntil": "1786320000"
  },
  "authoritySignature": "0x<65-byte-signature>",
  "methodProof": {}
}
```

## Verifier Flow

1. Resolve the live target text record and descriptor at one block.
2. Parse the URL and derive the HTTPS origin.
3. Calculate `valueHash`, common claim digest, and `proofKey`.
4. Fetch the well-known proof without credentials or redirects.
5. Parse and compare the complete common claim.
6. Resolve current ENS authority and validate its signature.
7. Require an empty `methodProof`.
8. Apply common lifecycle and cache rules.

## Validation Rules

The URL parser uses the WHATWG URL algorithm and its IDNA processing. Reject a
non-HTTPS scheme, credentials, fragment, empty or opaque host, invalid port, or
IPv6 zone identifier. Omit port 443 from the target and retain any other valid
explicit port.

| Check                                              | Failure              |
| -------------------------------------------------- | -------------------- |
| URL cannot produce a supported HTTPS origin        | `target_mismatch`    |
| `u` or `h` present                                 | `invalid_descriptor` |
| TLS, status, redirect, CORS, or media type invalid | `proof_unavailable`  |
| Envelope or `methodProof` invalid                  | `proof_invalid`      |
| Live origin differs from claim target              | `target_mismatch`    |

## Result

Successful validation demonstrates control of the serialized HTTPS origin for
the exact live ENS record and returns `verified/control`.

## Cache And Lifecycle

Maximum claim lifetime is 30 days. Positive caching is limited to five minutes
and may be shortened by HTTP freshness or client policy. Removing the proof
invalidates the method after the live publication cache expires.

## Security Considerations

The method uses same-origin publication as evidence of origin control. It does
not validate every path, resource, operator, or user of that origin. A
compromised origin can publish a valid proof.

## UI Copy

Allowed:

- `Control of the HTTPS origin was demonstrated for this ENS record.`
- `The HTTPS origin served a proof bound to this ENS record.`

Forbidden:

- `Official website.`
- `Safe website.`
- `Website owner verified.`

## Example

```text
text("url") = "https://example.com/profile"
text("verification[text][url]") = "ensrv1 a=1 m=https-origin.v1"
```

Derived target and proof location:

```text
target = https://example.com
https://example.com/.well-known/ens-record-verification/3e1afa3eb523cdefc3d8faa94c15e05fe1af4fb5096f71e127890e3763f5a380
```
