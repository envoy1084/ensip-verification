# Method: `https-origin.v1`

This method verifies that current exact-name authority authorized a URL-like
record and its HTTPS origin currently publishes the same proof.

## Profile

| Property                  | Value                          |
| ------------------------- | ------------------------------ |
| Relationship              | `control`                      |
| Records                   | HTTPS URL text records         |
| Freshness                 | `live-publication`             |
| Descriptor                | `ensrv1 a=1 m=https-origin.v1` |
| `u` and `h`               | Forbidden                      |
| Maximum claim lifetime    | 30 days                        |
| Maximum publication cache | 5 minutes                      |

## Target

The exact live text value MUST be valid UTF-8 and parse as an absolute HTTPS URL
under the WHATWG URL algorithm. IDNA processing follows that algorithm's
non-transitional ASCII host conversion.

Reject credentials, an empty or opaque host, malformed percent encoding, an
invalid port, or a scheme other than `https`.

The target is the serialized origin:

```text
https://<ascii-host>[:non-default-port]
```

Use lowercase scheme and ASCII DNS host, bracketed canonical IPv6, omit port
443, and retain any other valid port. Path, query, and fragment are excluded
from target but remain bound by raw `valueHash`.

## Proof Location

Compute common `proofKey`. Fetch:

```text
<target>/.well-known/ens-record-verification/<64-lowercase-hex-without-0x>
```

Requirements:

- status exactly `200`;
- media type `application/ens-record-verification+json`;
- no redirects;
- no cookies, authorization headers, or ambient credentials;
- common network and 256 KiB decoded-body limits.

## Proof

```json
{
  "v": "ensrv1",
  "claim": {
    "name": "alice.eth",
    "node": "0x...",
    "recordType": "text",
    "recordKey": "url",
    "valueHash": "0x...",
    "authorityVersion": "1",
    "method": "https-origin.v1",
    "target": "https://example.com",
    "issuedAt": "1783728000",
    "validUntil": "1786320000"
  },
  "authoritySignature": "0x...",
  "methodProof": {}
}
```

Current same-origin publication is target evidence. No second target signature
is required.

## Verification

1. Resolve live record and descriptor at one ENS block.
2. Parse the URL and derive target origin.
3. Compute `valueHash` and `proofKey`.
4. Fetch the deterministic proof under client privacy policy.
5. Parse the strict envelope and match all claim fields.
6. Verify current exact-name authority.
7. Apply claim and live-publication freshness.
8. Return `verified/control`.

Removing the proof revokes target participation after at most 5 minutes.

## Meaning

Allowed:

```text
HTTPS origin published a matching proof for this ENS record.
```

Forbidden:

```text
Official website
Safe website
Path owner verified
Legal domain owner
```
