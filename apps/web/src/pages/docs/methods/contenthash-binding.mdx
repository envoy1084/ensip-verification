# Method: `contenthash-binding`

`contenthash-binding` verifies that the current ENS authority signed a proof binding the live ENS `contenthash` value to the ENS name and record.

This method intentionally avoids requiring a manifest inside an immutable content root. Adding a manifest to a content-addressed directory can change the contenthash and cause circular authoring failures.

## Properties

| Property | Value |
| --- | --- |
| Method | `contenthash-binding` |
| Kind | `control` |
| Freshness class | `portable-signed` |
| Descriptor | `ensrv1 m=contenthash-binding u=<proof-uri> [h=<hash>]` |
| `h` policy | Required for mutable `u`; optional for content-addressed `u`. |

## Supported Records

```text
contenthash(node)
```

## Publisher Flow

1. Publish the content root and obtain the final contenthash.
2. Set the ENS contenthash record.
3. Compute:

```text
valueHash = keccak256(raw contenthash bytes)
```

4. Create the common claim with:

```text
recordType = "contenthash"
recordKey = ""
method = "contenthash-binding"
target = method-defined URI form of the contenthash
```

5. Sign the claim with the current ENS authority.
6. Publish the proof envelope at a content-addressed URI or mutable URI with descriptor `h`.
7. Set:

```text
text("verification[contenthash]") = "ensrv1 m=contenthash-binding u=ipfs://bafyProof"
```

## Proof Envelope

```json
{
  "v": "ensrv1",
  "claim": {
    "name": "alice.eth",
    "node": "0x...",
    "recordType": "contenthash",
    "recordKey": "",
    "valueHash": "0x...",
    "method": "contenthash-binding",
    "target": "ipfs://bafyContentRoot",
    "authorityProfile": "ens-mainnet-v1",
    "validUntil": "1783209600",
    "nonce": "0x..."
  },
  "authoritySig": {
    "type": "eip712",
    "signature": "0x..."
  }
}
```

## Verifier Flow

1. Resolve the live contenthash record.
2. Compute `valueHash` from raw contenthash bytes.
3. Resolve `verification[contenthash]`.
4. Require method `contenthash-binding`.
5. Fetch proof bytes from descriptor `u`.
6. Check `h` if present or required.
7. Parse proof envelope.
8. Check common claim fields and value hash.
9. Check `target` corresponds to the live contenthash under the method encoding.
10. Resolve current ENS authority and verify signature.
11. Check expiry and lifecycle rules.
12. Return `verified/control`.

## Security Notes

This method verifies intentional binding. It does not prove:

```text
content safety
publisher identity outside ENS
legal ownership
immutability of external gateways
freshness of the content itself
```
