# Method Family: `issuer-attestation.<format>`

This is an abstract method family, not a production method. The identifier
`issuer-attestation` MUST NOT appear in a descriptor.

A concrete format profile must define:

- immutable method identifier;
- credential serialization and signature algorithm;
- binding to the common claim digest;
- issuer identifier and key discovery;
- key rotation behavior;
- subject and target semantics;
- validity bounds;
- revocation protocol and maximum status age;
- client trust-policy inputs;
- strict proof schema;
- result issuer metadata;
- error mapping and UI language.

A cryptographically valid attestation from an issuer not accepted by client
policy returns `none/untrusted_issuer`. It never becomes globally trusted.

No issuer format is normative in the initial release.
