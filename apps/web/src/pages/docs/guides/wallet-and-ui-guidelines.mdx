# Wallet and UI Guidelines

## Fetch Defaults

| Context                            | Default                                                                          |
| ---------------------------------- | -------------------------------------------------------------------------------- |
| Passive profile                    | No direct third-party fetch; use no badge, fresh local result, or privacy proxy. |
| User selects Verify                | `fetch-on-action`.                                                               |
| Payment, sign-in, agent connection | Fresh ENS and method revalidation.                                               |
| Developer tooling                  | Direct fetch allowed with full network protections.                              |

`privacy_blocked` means verification was not performed. It is not proof failure.

## Relationship Copy

| Relationship/method | Recommended text                                      |
| ------------------- | ----------------------------------------------------- |
| `authorization`     | Current ENS authority authorized this record.         |
| `https-origin.v1`   | HTTPS origin published a matching proof.              |
| DNS TXT             | DNSSEC-authenticated zone published a matching proof. |
| EVM account         | Target EVM account signed a matching proof.           |
| Attestation         | `<issuer>` attested under `<policy>`.                 |

Do not use:

```text
Official
Trusted
Safe
Not a scam
Legal owner
Identity verified
Known recipient
```

## Failure Display

Most `none` results produce no badge. Developer views may display exact error,
retryability, block, authority source, proof source, and freshness.

Distinguish:

- not configured;
- not checked because privacy policy blocked retrieval;
- temporarily unavailable;
- checked and invalid;
- unsupported by this client.

## Assurance

Assurance metadata refines evidence but never creates another status or
relationship. Show DNSSEC only when actually validated. An absent field means
not checked or not applicable, not false.
