# Publish a Verification

Publish the proof before setting its verification text record in ENS. After
each change, verify the result from another client.

## Preconditions

Before signing:

1. resolve the exact target record through Universal Resolver;
2. determine current exact-name authority under the selected authority version;
3. derive the exact selector, raw `valueHash`, method target, and proof key;
4. choose `issuedAt` and `validUntil` within the method maximum lifetime;
5. verify that the signer is the current authority.

## Initial Publication

1. Construct the complete common claim.
2. Sign it with the current exact-name authority.
3. Produce method-specific evidence.
4. Serialize the closed proof envelope.
5. Publish the proof at the method-defined location.
6. If the descriptor uses `h`, hash the exact published response body bytes.
7. Fetch and validate the proof from an independent client.
8. Set the verification text record descriptor.
9. Resolve and verify the final ENS state.

Publishing the descriptor last reduces the interval in which ENS advertises an
unavailable proof. It does not make ENS and external publication atomic.

## Renewal

To renew an unchanged record:

1. create a claim with new timestamps;
2. obtain fresh required signatures;
3. replace the proof resource;
4. update descriptor `h` if present;
5. validate the new state.

The proof key does not change when only record value or timestamps change.

## Record Rotation

A target record change changes `valueHash` and may change the method target.
Create and publish the new proof before updating the descriptor when possible.
Expect a temporary `none` result while distributed state converges.

Do not serve several candidate envelopes and require clients to search for one
that validates. One descriptor and proof key select one current proof.

## Revocation

Delete the verification text record to revoke verification from ENS. Changing
the target record, descriptor, or exact-name authority also invalidates the old
proof after a fresh evaluation.

Deleting a remote proof without deleting the descriptor changes the result to
`proof_unavailable`; it is not a complete ENS-side revocation procedure.
