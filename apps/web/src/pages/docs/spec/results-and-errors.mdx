# Results

A verifier exposes two public statuses:

```ts
type VerificationResult =
  | {
      status: "verified";
      relationship: "authorization" | "control" | "attestation";
      method: string;
      name: string;
      node: `0x${string}`;
      recordType: string;
      recordKey: string;
      target: string;
      validUntil: number;
      checkedAt: number;
      cacheUntil: number;
    }
  | {
      status: "none";
      error: VerificationError;
      retryable: boolean;
      checkedAt: number;
    };
```

The TypeScript shape is an SDK interface, not a wire format. Implementations in
other languages expose equivalent fields.

## Relationships

| Relationship    | Required evidence                           | Permitted display meaning                                                  |
| --------------- | ------------------------------------------- | -------------------------------------------------------------------------- |
| `authorization` | Current exact-name authority signature      | Current ENS authority authorized the exact live record.                    |
| `control`       | Authorization plus method target evidence   | Method evidence demonstrated control of the record's canonical target.     |
| `attestation`   | Authorization plus accepted issuer evidence | An issuer accepted under client policy attested to the record-bound claim. |

Do not infer safety, reputation, legal ownership, or ENS endorsement.

## Errors

Every non-positive evaluation returns `status: "none"`. The error explains the
failed stage and does not alter the underlying resolver record.

The canonical error codes, precedence, and retry categories are defined in the
[Error Reference](../reference/errors). Method pages identify the errors
specific to their validation step.

## Evidence Metadata

An implementation may expose diagnostic evidence:

```ts
type VerificationEvidence = {
  authority?: "eoa" | "erc1271";
  dnssec?: "validated";
  proofIntegrity?: "hash-pinned" | "content-addressed";
  publication?: "live" | "portable" | "issuer-revocable";
};
```

Only report a property after performing that check. Evidence metadata does not
create another status or relationship.
