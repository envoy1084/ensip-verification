# Verification Descriptor

The descriptor is the compact value stored in the verification text record.
Proof payloads remain offchain.

## Grammar

```text
descriptor  = "ensrv1" 1*(SP field)
field       = field-name "=" field-value
field-name  = 1*(%x61-7A / %x30-39 / "-")
field-value = 1*(%x21-7E)
```

The complete version-one form is:

```text
ensrv1 a=<authority-version> m=<method> [u=<uri>] [h=<hash>]
```

No other fields are defined.

## Fields

| Field | Rule                                                                                            |
| ----- | ----------------------------------------------------------------------------------------------- |
| `a`   | Required exactly once. Canonical unsigned decimal authority version. Version 1 is defined here. |
| `m`   | Required exactly once. Immutable method identifier.                                             |
| `u`   | Absolute proof URI under method scheme rules.                                                   |
| `h`   | Lowercase `0x`-prefixed 32-byte `keccak256` hash.                                               |

Method identifiers match:

```text
[a-z0-9][a-z0-9.-]{0,63}
```

## Parser Rules

A parser MUST reject:

- a version token other than `ensrv1`;
- missing or duplicate `a` or `m`;
- duplicate fields;
- unknown fields;
- empty field names or values;
- non-ASCII bytes;
- control characters or spaces in values;
- non-canonical or unsupported `a`;
- malformed `h`;
- a descriptor longer than 2,048 bytes;
- a `u` value longer than 1,024 bytes.

Unknown fields are invalid. Older clients must not ignore a future
security-critical constraint. Compatible metadata belongs in the proof payload;
incompatible descriptor changes require a new version.

## Method Requirements

Each method declares one descriptor shape:

| Shape     | Meaning                                                        |
| --------- | -------------------------------------------------------------- |
| `a m`     | Proof location is derived or no external resource is required. |
| `a m u`   | Descriptor selects a resource authenticated by signed content. |
| `a m u h` | Descriptor additionally selects exact resource bytes.          |
| `a m h`   | Derived proof location with ENS-side exact-byte selection.     |

Examples:

```text
ensrv1 a=1 m=https-origin.v1
ensrv1 a=1 m=authority-signature.v1 u=https://proofs.example/p/123
ensrv1 a=1 m=account-signature.eip155.v1 u=https://proofs.example/p/456 h=0xabcd...
```

## Proof Bytes

`h` hashes the retrieved response body after transfer decoding and content
decoding, before UTF-8 decoding or JSON parsing:

```text
h = keccak256(proofResourceBytes)
```

HTTP headers, chunk framing, and compressed transfer bytes are not included.
The fetcher MUST reject transparent transformations that prevent reconstruction
of the pinned body bytes.

## Fetch Limits

Common minimum requirements:

- only method-approved URI schemes;
- no loopback, private, link-local, multicast, or reserved network targets;
- DNS rebinding checks on every connection and redirect;
- at most 3 redirects;
- at most 10 seconds total request time;
- at most 256 KiB decoded proof bytes;
- bounded decompression ratio;
- valid TLS for HTTPS;
- no `file:`, `data:`, or local IPC schemes.

Method profiles MAY be stricter.
